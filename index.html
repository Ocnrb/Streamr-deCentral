          100% Client-Side — All code runs entirely in your browser. No backend servers, no data collection.

          • The Graph — Operator & delegator data via decentralized indexing

          • Polygon RPC — Direct blockchain queries for real-time data

          • Streamr Network — Live node heartbeats and DATA price via WebSocket streams
