Streamr deCentral

Community Dashboard

Streamr deCentral is a community-built dashboard for exploring and managing the Streamr Network ecosystem.

Security & Privacy

100% Client-Side — All code runs entirely in your browser. No backend servers, no data collection.

Private Key Security — Keys are encrypted using Ethereum Keystore V3 standard and stored locally. Never transmitted anywhere.

Open Source — Fully transparent codebase.

Data Sources

• The Graph — Operator & delegator data via decentralized indexing

• Polygon RPC — Direct blockchain queries for real-time data

• Streamr Network — Live node heartbeats and DATA price via WebSocket streams

• Etherscan API — Transaction History
