The Streamr Network ↗

Serverless real-time data and media broadcasts that scale automatically

Streamr is pub/sub without a broker. Every stream forms its own constellation of publishers and subscribers, a self-organizing overlay linked directly peer to peer, and thousands of them share one global mesh. No servers, no trackers, no permission needed. Free and open source, and every node that joins, even a browser, adds capacity.

Layer 0 · Global DHT

A phone book for the whole network

An r-Kademlia DHT spans every node. It brings new nodes in, keeps where each stream can be joined and routes messages to any node in a few hops, including the signaling that opens direct links through firewalls and NATs.

Layer 1 · Stream coordination

Every stream finds its peers

Each stream has its own hybrid DHT, Kademlia for robustness and a locality-aware ring for closeness. It finds peers nearby for speed and farther away for resilience, with no connections of its own.

Layer 2 · Data delivery

A mesh that stays fast

Subscribers link directly to at least four peers, mostly close by, over WebSocket where a node is reachable and WebRTC everywhere else, even in a browser. In tests with 2 000 nodes, messages reached everyone in under 120 ms on average.

Tested across 17 regions ↗

On-chain where it counts

Streams, their permissions and the incentives live in smart contracts on Polygon, and identities are Ethereum keys that sign every message. The data itself flows off-chain, so creating a stream is one transaction and publishing or subscribing costs nothing.

Plugs into anything

Build with the TypeScript SDK in Node.js or the browser, or run a Streamr node and publish or subscribe through its MQTT, WebSocket and HTTP interfaces, from any language or device.

Incentives and DATA

Incentives are opt-in

Using the network is free. Sponsored nodes are plug-and-play relays, like TURN servers for a stream, adding bandwidth for wide broadcasts, relaying for publishers behind NATs or on weak links and keeping the stream reachable 24/7.

Paid in DATA

DATA is the ERC-20 utility token of Streamr. Sponsors pay it into sponsorships, smart contracts that tie off-chain streaming to on-chain rewards. Operators stake it there and earn for relaying the data, and delegators back them. The result is a decentralized live CDN.

Checked by the operators

Inside each sponsorship, operators keep each other honest. A node that does not do its job can be flagged, operators picked as reviewers vote on it, and a kick slashes part of its stake.

DAO governance

Apart from that work, DATA is voting power in the Streamr DAO. Token holders vote on proposals that set the rules and economic parameters of the network.
